# GlobeTrotter - Screen & User Interface Breakdown

Below is the initial screen inventory for the GlobeTrotter multi-city travel planning application:

1. **Landing & Overview Page (`/`)**:
   - GlobeTrotter visual branding, platform capabilities, call-to-action buttons ("Start Planning", "Sign In").
2. **Authentication Pages (`/login`, `/register`)**:
   - User sign-in and account creation forms with validation feedback.
3. **Dashboard / My Trips (`/dashboard`)**:
   - Overview of active, upcoming, and past multi-city trips.
4. **Trip Builder / Multi-City Planner (`/planner/new`)**:
   - Interactive multi-city route selector, date picker, budget allocator, and pacing preferences.
5. **Trip Details & Itinerary Viewer (`/trips/:id`)**:
   - Detailed timeline view of destinations, activities, budgets, and interactive map preview.
6. **User Profile & Preferences (`/profile`)**:
   - Account configuration, travel preferences management.
